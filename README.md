# Tofunmi Akande — portfolio

Static site: `index.html` plus `assets/` (images, CV PDF, favicon, social preview image).
No build step.

## Publish on GitHub Pages
1. On GitHub, create a **public** repository named exactly `akande-tofunmi.github.io`.
2. Upload everything in this folder (`index.html`, `README.md`, the `assets` folder) to the repository root.
3. Open **Settings → Pages**, set Source to **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
4. After a minute or two the site is live at https://akande-tofunmi.github.io

## Updating
- New CV: replace `assets/Akande_Oluwatofunmi_CV_2026.pdf` (keep the same file name).
- Text: edit `index.html` and commit; Pages redeploys automatically.
